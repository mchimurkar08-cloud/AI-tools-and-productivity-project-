3. Build a simple AI-powered application

Project idea

The application accepts a topic and generates:
 -A simple explanation
 -Key points
 -Quiz questions
 -A short revision summary
 
 Basic workflow
 
User enters a topic
        ↓
AI receives a prompt
        ↓
AI generates learning material
        ↓
Application displays the result

*Example prompt

Explain the following topic:
{TOPIC}

Provide:
1. A simple explanation
2. Five important points
3. Three quiz questions
4. A short revision summary

A simple python + AI API application, or start with a no-code prototype using an AI chatbot.

*Example interaction

User:
Explain Machine Learning

AI Study Assistant:

Machine Learning is a branch of AI where computers
learn patterns from data and use those patterns
to make predictions or decisions.

Key points:
1. ML learns from data.
2. It can make predictions.
3. Training data is important.
4. Models can be evaluated using test data.
5. ML is used in many real-world applications.

Quiz:
1. What is Machine Learning?
2. Why is training data important?
3. What is a prediction?
